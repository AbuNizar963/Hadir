# Flutter Migration — حاضِر

هذه الصفحة هي نقطة البداية لتحويل تطبيق **حاضِر** من واجهة React/Vite الحالية إلى تطبيق Flutter.

## الوضع الحالي

- المصدر الحالي: React + TypeScript + Vite.
- Backend الحالي: Cloudflare D1، مع R2 للصور عند التفعيل.
- فرع العمل: `flutter-migration`.
- الهدف: بناء تطبيق Flutter يحافظ على الوظائف الحالية مع واجهة ومكونات أصلية للموبايل.

## نطاق التحويل

1. إنشاء مشروع Flutter منظم إلى `core / data / domain / presentation`.
2. نقل المصادقة والأدوار والصلاحيات.
3. نقل تسجيل الحضور والانصراف.
4. دمج GPS والتحقق من المسافة عن موقع العمل.
5. دمج QR Scanner.
6. نقل الإشعارات وسجل التدقيق والطلبات.
7. نقل شاشات الموظف والإدارة تدريجيًا.
8. ربط Flutter بنفس Backend الحالي عبر API بدل إعادة بناء منطق الخادم داخل التطبيق.

## مبادئ التنفيذ

- لا نغيّر Backend إلا عند الحاجة.
- لا نبدأ بتحويل كل الملفات دفعة واحدة؛ نبدأ بشريحة صغيرة قابلة للتشغيل.
- نُبقي منطق الأعمال منفصلًا عن Widgets.
- نضيف اختبارات للمنطق الحساس قبل نقل الوظائف الحرجة.
- الأسرار ومفاتيح الخدمات لا تُضمّن داخل تطبيق Flutter.

## أول خطوة

إنشاء هيكل Flutter الأساسي ثم تنفيذ تدفق تسجيل الدخول وحالة الجلسة، وبعدها شاشة الموظف الأساسية للحضور والانصراف.

## ملاحظة

هذه الصفحة توثيق لبداية الهجرة وليست استبدالًا للنسخة الحالية. يمكن تشغيل النسخة الحالية بالتوازي إلى أن تكتمل كل مرحلة من مراحل التحويل.
